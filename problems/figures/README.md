# Question figures

These are the original figure files used by the selected-problem source. They
were moved here from the repository root without changing their contents.
The problem-book entry point sets the figure search path, so each question can
refer to its original filename.

The filenames are historical and do not always match the current problem
numbers. In particular, problems 22 and 36 use
`Problem_21_Figure.png` and `Problem_31_Figure.png`, respectively. Problem 27
uses a diagram drawn in LaTeX rather than a PNG.

`Problem_24_Figure.png` and `Problem_38_Figure.png` are not referenced by the
current problem set. They are retained for reference; their unused status does
not establish their provenance or reuse rights. Source-paper references for the
selected questions are recorded in `data/problem-sources.json`.
