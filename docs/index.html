A reading route

  1. Choose a topic in the study guide. Read the conditions, formulas and common pitfalls.
  2. Try an example before opening its solution, then follow a related-problem link.
  3. Compare your reasoning with the key insight and return to the guide when an assumption is unclear.

Download both PDFs into the same folder to use their companion-file links. PDF viewer support for links between files varies.
